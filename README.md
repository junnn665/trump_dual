# ♠♥ TRUMP DUEL ♦♣（トランプ・デュエル）

トランプ1組（52枚＋ジョーカー）で遊ぶ、デュエル・マスターズ風のカードバトルゲームです。
ブラウザだけで動き、スマホでも遊べます。

## 遊び方

- **CPUと対戦**：やさしい／ふつう／つよい の3段階
- **オンライン対戦**：4ケタの部屋番号・招待リンク・QRコードで、はなれた友だちと通信対戦。観戦・スタンプ・同じ部屋で「もう一回」もできます
- **チャレンジ（ボス戦）**：特殊ルールのボス8体。クリアするとカードの裏面デザインが手に入る
- **カード図鑑**：54枚すべての絵柄と能力を見られます
- **デッキ編成**：54種類から40枚を選んでマイデッキを作れる（おまかせ・速攻・要塞・大型・ロイヤル狙いのおすすめつき）。CPU戦・チャレンジ・オンラインで使えます
- **バトルロイヤル**：3〜4人で同時に戦い、最後まで生き残った人の勝ち。CPU戦（3人・4人）とオンライン（最大4人の部屋）で遊べる
- **金・虹カード**：勝つと特別版カードがもらえる（パック開封演出つき）。同じカードの金をもう1枚引くと虹に進化。性能は同じで見た目がキラキラに
- **実績と称号**：23種類の実績。解除した実績の名前を「称号」として名前の横に表示（オンラインの相手にも見える）
- **デッキの決まり**：40枚。同じカードは4枚まで、黒・赤ジョーカーはそれぞれ1枚まで
- **デッキコード**：マイデッキを `TD2-XXXX-…` の短いコードにして、別の端末に引き継いだり友だちに送ったりできる
- **デッキの保存枠**：名前つきで5つまで。ホームの「🗂 ▼」で対戦前にえらぶ
- **CPUのタイプ**：バランス／速攻／守り／ロイヤル狙い（タイプに合ったデッキで来る）
- **エフェクトの着せ替え**：標準・炎・桜・雷・氷
- **3Dカードビューア**：図鑑やホームのカードをタップすると、指で回して表と裏を眺められる
- **大会**：あなた＋CPU7人の8人トーナメント。3回勝てば優勝（金・虹カード5枚）
- **ゴーストバトル**：ほかの人が登録したデッキとCPUが戦う。ゴースト側の戦績も記録される
- **プロフィール**：よく使うスート・勝率・最高連勝・いちばん使ったカード。オンラインの待合室で名前をタップすると相手のも見られる
- **遊びやすさ**：💡おすすめの一手、📋早見表、左手モード、色覚サポート（Okabe–Ito配色）、クリーチャーのセリフ、効果音テーマ（標準・8bit・和風・SF）、試合後の振り返りグラフ
- **ランキング**：オンライン対戦の勝ち負けでレート（はじめ1500）が上下し、上位100人を表示
- **ホーム画面に追加**（PWA）：アプリのように全画面で起動、オフラインでもCPU戦・チャレンジが遊べます

### 新しいルール
- **マリガン**：最初の手札を1回だけ引き直せる
- **後攻ボーナス**：先攻以外はシールド+1（CPU同士の対戦で先攻の勝率が約51%になるよう調整）
- **スートの相性**：♠→♥→♦→♣→♠ の順に有利。バトルでパワー+1000
- **赤・黒のジョーカー**：デッキに2枚。黒は攻撃的（SA・BL・8000以下破壊）、赤は守り（RB・DR・シールド+1）
- **2対2**：CPU戦とオンライン（ちょうど4人）で遊べるチーム戦
- **コンボ召喚**：同じ数字のクリーチャー2枚を同時に出すと合計コスト-1
- **超進化**：場の同じスートのQにKを重ねる（コスト5）とパワー20000・すぐ攻撃
- **墓地召喚**：1試合1回、墓地5枚を除外して山札か墓地のジョーカーを呼ぶ
- **シールド仕込み**：試合の最初に、手札1枚をシールドと入れかえられる
- **リベンジ**：1対1で負けた側は、再戦の先攻・後攻をえらべる（オンラインも）
- **役ボーナス**：バトルゾーンのクリーチャーでペア・スリーカード・ストレート・フラッシュなどができるとパワーアップ
- **ロイヤルストレートフラッシュ**：同じスートの10・J・Q・K・Aがバトルゾーン＋マナにそろうと即勝利
- **持ち時間**：オンラインは1ターン60秒（ブロック等の選択は20秒）

### 操作
- 手札を上スワイプ＝召喚／呪文、下スワイプ＝マナに置く（タップでも操作できます）
- キラカード：A・Q・K・JOKER はスマホを傾けると光が動きます（設定でOFF可）
- カードを長押しすると大きく表示（役ボーナス込みのパワーも見られる）
- 設定で効果音・BGMの音量を調整。BGMはタイトル／バトル／ボス戦／ピンチ（シールド残り1枚以下）で切りかわります

### 勝ち方
相手のシールド5枚をすべてブレイクし、シールドが0枚の相手に **ダイレクトアタック** を決めたら勝ち！

### ターンの流れ
1. アンタップ → 1枚ドロー（先攻1ターン目は引かない）
2. 手札を1枚マナに置ける（1ターン1回）
3. マナをタップしてクリーチャー召喚・呪文
4. クリーチャーで攻撃 → ターン終了

### スート＝文明
カードを使うには、コスト分のマナに加えて **同じスートのマナが1枚以上** 必要です。

| スート | 文明 | 能力 |
|---|---|---|
| ♠ | 黒鋼 | スピードアタッカー（出たターンに攻撃できる。コスト5以下のカードだけ） |
| ♣ | 翠樹 | ブロッカー（攻撃を代わりに受ける） |
| ♥ | 紅炎 | リバース（攻撃時パワー+2000。破壊されたらマナになり1枚引く） |
| ♦ | 蒼晶 | ドロー（出たとき1枚引く。次の自分のターンまでブロッカー） |

### カードの種類

| カード | 内容 |
|---|---|
| 2〜10 | クリーチャー。パワー＝数字×1000。9・10はW・ブレイカー |
| A | ドラゴン。パワー12000・W・ブレイカー。攻撃時にパワー3000以下を破壊 |
| J | 呪文（S・トリガー）。スートごとに 除去／タップ／回収／ドロー |
| Q | 進化クリーチャー。同じスートの味方に重ねて即攻撃。パワー11000・W |
| K | キング。パワー15000・T・ブレイカー。登場時にスートごとの強力な効果 |
| JOKER | 全文明・全能力持ち・S・トリガーの切り札 |

## 演出
召喚カットイン、シールドブレイクの破片、S・トリガー発動、VSバトル、ダイレクトアタック、勝利の紙吹雪、効果音とBGM（Web Audioで合成）など。
設定から演出スピード（1x〜3x）や軽量モードを変えられます。

## オンライン対戦のしくみ
「都道府県ゲーム（prefpack）」と同じ Firebase Realtime Database（`odeko-ddb38`）を使っています。

- 部屋：`rooms/duel-<4ケタ>`（待合室・参加者・スタンプ・投了）
- レート：`rooms/duel-ranking/<端末ID>`（name, rating, w, l）
- 手順：`rooms/duel-<4ケタ>-m/r<回>/m00000…`
- 2台が同じシードで同じルールエンジンを動かし、操作と選択だけを順番に送り合う方式（ロックステップ）。
  途中から観戦に入った人や再読みこみした人は、それまでの手順を早送りして同じ盤面に追いつきます
- 作ってから24時間たった `duel-` の部屋は、次に部屋を作ったときに自動で消えます
- Firebase のルールは prefpack と同じ（`rooms` の下を読み書き可）でそのまま動きます

テスト：`node tests/lockstep.js`（2台＋途中観戦の盤面一致）、`tests/online.html`（通信なしで3画面をつないで確認）

## 公開方法（GitHub Pages）
1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main` / `/(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/trump_dual/` で遊べます

## ローカルで動かす
ES Modules を使っているので、ファイルを直接開くのではなく簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
