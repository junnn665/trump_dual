# ♠♥ TRUMP DUEL ♦♣（トランプ・デュエル）

トランプ1組（52枚＋ジョーカー）で遊ぶ、デュエル・マスターズ風のカードバトルゲームです。
ブラウザだけで動き、スマホでも遊べます。

## 遊び方

- **CPUと対戦**：やさしい／ふつう／つよい の3段階
- **2人で対戦**：1台のスマホやPCを交代しながら対戦（ターンごとに目隠し画面が入ります）

### 勝ち方
相手のシールド5枚をすべてブレイクし、シールドが0枚の相手に **ダイレクトアタック** を決めたら勝ち！

### ターンの流れ
1. アンタップ → 1枚ドロー（先攻1ターン目は引かない）
2. 手札を1枚マナに置ける（1ターン1回）
3. マナをタップしてクリーチャー召喚・呪文
4. クリーチャーで攻撃 → ターン終了

### スート＝文明
カードを使うには、コスト分のマナに加えて **同じスートのマナが1枚以上** 必要です。

| スート | 文明 | 能力 |
|---|---|---|
| ♠ | 黒鋼 | スピードアタッカー（出たターンに攻撃できる） |
| ♣ | 翠樹 | ブロッカー（攻撃を代わりに受ける） |
| ♥ | 紅炎 | リバース（破壊されたらマナになる） |
| ♦ | 蒼晶 | ドロー（出たとき1枚引く） |

### カードの種類

| カード | 内容 |
|---|---|
| 2〜10 | クリーチャー。パワー＝数字×1000。9・10はW・ブレイカー |
| A | ドラゴン。パワー12000・W・ブレイカー。攻撃時にパワー3000以下を破壊 |
| J | 呪文（S・トリガー）。スートごとに 除去／タップ／回収／ドロー |
| Q | 進化クリーチャー。同じスートの味方に重ねて即攻撃。パワー11000・W |
| K | キング。パワー15000・T・ブレイカー。登場時にスートごとの強力な効果 |
| JOKER | 全文明・全能力持ち・S・トリガーの切り札 |

## 演出
召喚カットイン、シールドブレイクの破片、S・トリガー発動、VSバトル、ダイレクトアタック、勝利の紙吹雪、効果音とBGM（Web Audioで合成）など。
設定から演出スピード（1x〜3x）や軽量モードを変えられます。

## 公開方法（GitHub Pages）
1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main` / `/(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/trump_dual/` で遊べます

## ローカルで動かす
ES Modules を使っているので、ファイルを直接開くのではなく簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 構成

```
index.html        画面の骨組み
css/style.css     デザイン・アニメーション
js/cards.js       カード定義（トランプ → クリーチャー/呪文 への変換）
js/engine.js      ルール処理（DOM非依存）
js/ai.js          CPUの思考ルーチン
js/ui.js          盤面描画・操作・演出
js/fx.js          パーティクル・カットイン・画面揺れ
js/sound.js       効果音・BGM
js/main.js        起動・画面遷移・設定
tests/simulate.js CPU同士の自動対戦テスト（node tests/simulate.js 300）
```
